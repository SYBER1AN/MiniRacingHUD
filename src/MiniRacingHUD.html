☝️ Настройка (с приложения)

• ВАЖНО! Для настройки виджета, окно с HTML должно иметь достаточную высоту, иначе включается упрощённый режим виджета. Все настройки сохраняются в виде пресетов. Вы можете создать несколько пресетов для каждой игры.

1. Кликните на пустой слот оси или кнопки

2. Подвигайте ось или нажмите кнопку

3. Если нужно, настройте диапазон оси и инверсию

4. Не стесняйтесь потыкать другие кнопочки 😉

5. Нажмите «Сохранить» и настроенный пресет сохранится в папку presets в папке программы

6. Для работы UDP-телеметрии оставьте приложение включённым

☝️ Настройка (браузерный вариант)

• ВАЖНО! Для настройки виджета, окно с HTML должно иметь достаточную высоту, иначе включается упрощённый режим виджета. После настройки и сохранения изменений основной HTML-файл и файл конфигурации NoApp.js должны лежать в одной папке!

1. Кликните на пустой слот оси или кнопки

2. Подвигайте ось или нажмите кнопку

3. Если нужно, настройте диапазон оси и инверсию

4. Не стесняйтесь потыкать другие кнопочки 😉

5. Нажмите «Сохранить» и настроенный файл скачается в «Загрузки». Скорее всего, сработает защита браузера 🥴, не пугайтесь, она среагирует так же на скачивание любого другого JS-файла

6. Поместите загруженный файл в папку с основным HTML-файлом

7. Пресеты и телеметрия игры доступны только при использовании приложения!

☝️ Параметры в адресной строке

• Параметр ?preset=X загружает пресет presets/X.js

• Параметр ?config=X.js загружает произвольный JS-конфиг из корня

• Параметр ?steering=X устанавливает угол поворота руля на X градусов

• Параметр ?scale=X устанавливает масштаб виджета в процентах (100–300)

• Параметр ?nogears полностью отключает индикатор передач

• Параметр ?mw=N выбирает слот мультивиджета (1-6)

• Возможно использовать параметры вместе через &, например: ...HUD.html?preset=DR2&steering=420
